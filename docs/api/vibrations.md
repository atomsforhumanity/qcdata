# Vibrations and thermochemistry

A `hessian` result holds the harmonic analysis and thermochemistry with the choices behind
them (masses, projection, standard state, symmetry number, entropy model), so frequencies and
free energies can be compared across programs. `SinglePointData.freqs_wavenumber`,
`normal_modes_cartesian` and `gibbs_free_energy` are filled from them when a program does not
give them itself.
