# Basis sets and orbitals

`Wavefunction.orbitals` holds molecular orbitals with the basis set they expand in and the
AO convention their coefficients follow, so they can start another program's SCF, be plotted,
or be compared across programs. Programs fill it on request (`output.orbitals`).
