    Vibrations and thermochemistry¶

    A hessian result holds the harmonic analysis and thermochemistry with the choices behind them (masses, projection, standard state, symmetry number, entropy model), so frequencies and free energies can be compared across programs. They are the only home of frequencies, normal modes and free energies on SinglePointData.

    qcdata.VibrationalAnalysis ¶

    The harmonic analysis of a Hessian, modes in ascending order of frequency.

    Attributes:

    Name Type Description
    masses SerializableVector

    Mass of each atom used (u), in structure order.
    projection Projection

    What was projected out of the mass-weighted Hessian.
    frequencies SerializableVector

    Frequency of every mode analysed (cm^-1), ascending; imaginary modes are negative. Without full projection the translation/rotation-like modes are included and flagged in external.
    external list[bool]

    Per mode, whether it is a translation/rotation rather than a vibration. Empty means no mode is external.
    normal_modes_cartesian SerializableTensor3D

    n_modes x n_atoms x 3 unit-length Cartesian displacements (dimensionless, sign arbitrary), as SinglePointData.normal_modes_cartesian.
    normal_modes_mass_weighted SerializableMatrix | None

    n_modes x 3N orthonormal eigenvectors of the mass-weighted Hessian.
    reduced_masses SerializableVector | None

    Per mode (u): 1 / |M^-1/2 L|^2 for the mass-weighted eigenvector L.
    force_constants SerializableVector | None

    Per mode (mdyn/angstrom): reduced mass times eigenvalue, negative for imaginary modes.
    ir_intensities SerializableVector | None

    Per mode (km/mol).
    dipole_derivatives SerializableMatrix | None

    3N x 3 atomic polar tensors d(mu_c)/d(X) (e), the input of ir_intensities; row 3a + i for atom a and Cartesian component i.
    rotor_type RotorType | None

    Atom, linear, or nonlinear.
    moments_of_inertia SerializableVector | None

    Principal moments (u bohr^2), ascending.
    rotational_constants list[float | None] | None

    A >= B >= C (cm^-1); None for a zero moment.
    point_group str | None

    Schoenflies symbol of the structure with these masses.
    symmetry_number int | None

    The rotational symmetry number used.
    symmetry_number_source str | None

    "detected" or "input".

    def imaginary_frequencies(self, cutoff: float = 0.0) -> np.ndarray:
    """Imaginary vibrational frequencies (negative, cm^-1).

    Args:
        cutoff: Only modes below ``-cutoff`` count (cm^-1, positive). Programs
            differ in their default (xtb and axtb ignore modes above -20 cm^-1),
            so the stored data apply none and the caller chooses.

    Returns:
        The imaginary frequencies, most negative first.
    """
    f = self.vibrational_frequencies
    return f[f < -abs(cutoff)]

    def n_imaginary(self, cutoff: float = 0.0) -> int:
    """Number of imaginary vibrations below ``-cutoff`` cm^-1.

    Args:
        cutoff: See `imaginary_frequencies`.

    Returns:
        The count.

    return len(self.imaginary_frequencies(cutoff))

    qcdata.Thermochemistry ¶

    Ideal-gas thermochemistry at one temperature and standard state.

    Attributes:

    Name Type Description
    temperature float

    Temperature (K).
    pressure float | None

    Pressure of an ideal-gas standard state (Pa).
    concentration float | None

    A concentration standard state instead (mol/L, e.g. 1 M).
    electronic_energy float

    The electronic energy the corrections were added to (Eh).
    zero_point_energy float

    Zero-point vibrational energy (Eh).
    electronic ThermoTerm | None

    The electronic contribution (degeneracy entropy).
    translational ThermoTerm | None

    The translational contribution.
    rotational ThermoTerm | None

    The rotational contribution.
    vibrational ThermoTerm | None

    The vibrational contribution (including the zero-point energy).
    total ThermoTerm

    All contributions plus the electronic energy.
    symmetry_number int | None

    The rotational symmetry number used.
    electronic_degeneracy float | None

    The electronic degeneracy used (e.g. the multiplicity).
    entropy_model EntropyModel

    How vibrational entropy was computed.
    enthalpy_model EnthalpyModel

    How vibrational energy and enthalpy were computed.
    qrrho_frequency float | None

    The quasi-RRHO switching or cutoff frequency (cm^-1).
    qrrho_alpha float | None

    The exponent of Grimme's damping function.
    qrrho_bav float | None

    Grimme's average moment of inertia B_av (kg m^2).
    frequency_scale_factor float

    The factor frequencies were scaled by.
    excluded_imaginary list[float]

    Imaginary frequencies left out (cm^-1, negative), e.g. a transition state's reaction coordinate.
    inverted_imaginary list[float]

    Imaginary frequencies treated as real (cm^-1, negative).

    qcdata.ThermoTerm ¶

    One contribution to the thermochemistry, or the total.

    Conventions: the vibrational energy includes the zero-point energy; pV = kT is in the translational enthalpy; the electronic term's energy is the electronic energy itself only in Thermochemistry.total, which includes it.

    Attributes:

    Name Type Description
    energy float | None

    Internal energy U (Eh).
    enthalpy float | None

    Enthalpy H (Eh).
    entropy float | None

    Entropy S (Eh/K).
    cv float | None

    Heat capacity at constant volume (Eh/K).
    cp float | None

    Heat capacity at constant pressure (Eh/K).
    gibbs float | None

    Gibbs energy G = H - TS (Eh).

    qcdata.Projection ¶

    What was projected out of the mass-weighted Hessian before diagonalization.

    qcdata.EntropyModel ¶

    How vibrational entropy is computed.

    Attributes:

    Name Type Description
    rrho

    Rigid rotor, harmonic oscillator for every mode.
    qrrho_grimme

    Grimme's quasi-RRHO: low modes interpolated to free rotors (Chem. Eur. J. 18, 9955 (2012)); parameters in Thermochemistry.qrrho_*.
    quasiharmonic_truhlar

    Truhlar's quasi-harmonic: frequencies below a cutoff raised to it.

    qcdata.EnthalpyModel ¶

    How vibrational energy and enthalpy are computed.

    Attributes:

    Name Type Description
    rrho

    Harmonic oscillator for every mode.
    qrrho_head_gordon

    Head-Gordon's quasi-RRHO enthalpy (J. Phys. Chem. C 119, 1840 (2015)).
